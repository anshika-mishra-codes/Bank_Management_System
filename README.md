
# Bank Management System

A Python-based Bank Management System built using Object-Oriented Programming (OOP) and MySQL. The application manages customer accounts and banking transactions through a menu-driven interface.

## Features

- **Account Creation:** Create and manage customer bank accounts.
- **Deposit:** Deposit money into existing accounts.
- **Withdrawal:** Withdraw money with balance validation.
- **Balance Inquiry:** Check the current account balance.
- **Transaction Management:** Maintain transaction records.
- **Database Integration:** Store and manage account and customer information using MySQL.
- **Input Validation:** Handle invalid inputs and basic transaction constraints.

## Technologies Used

- **Programming Language:** Python
- **Database:** MySQL
- **Concepts:** Object-Oriented Programming (OOP), CRUD Operations, SQL Queries, Input Validation

## Prerequisites

Make sure you have the following installed:

- Python 3.x
- MySQL Server
- MySQL Workbench (optional)

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd Bank-Management-System
   ```

3. Set up your MySQL database and configure the database connection in the project.

4. Install the required Python dependencies, if applicable:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   python main.py
   ```
